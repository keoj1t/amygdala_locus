> **LOCUS 2026** — высокопроизводительный движок генерации верифицированных визуальных и инфраструктурных профилей университетов. Система в реальном времени собирает реальные студенческие фотографии и отзывы, отсекает стоковые рендеры с помощью мультимодального ИИ, рассчитывает метрику достоверности (**Trust Score**) и предоставляет абитуриентам объективную картину кампуса за **<= 30 секунд**.

---

## 1. 🎯 Задача (Problem & Goal)

* **Проблема:**
  * Абитуриенты и их родители сталкиваются с глянцевыми маркетинговыми буклетами, отфотошопленными рендерами и стоковыми изображениями, которые скрывают реальное состояние общежитий, аудиторий и лабораторий.
  * Традиционные агрегаторы содержат статичные, захардкоженные и часто устаревшие данные о стоимости жизни, климате, безопасности и транспортной доступности.
  * Поиск честных отзывов студентов на форумах (Reddit, студенческие треды) занимает часы ручного серфинга.
* **Цель:**
  * Автоматическая генерация комплексного, динамического и **100% верифицированного профиля любого ВУЗа мира за время <= 30 секунд**.
  * Полное исключение стоковых, векторных и фейковых изображений с присвоением прозрачного индекса доверия (**Trust Score**).

---

## 2. 💡 Решение (Solution & Killer Features)

### 🟢 1. AI Photo Provenance & Verification (Trust Score)
Движок многоуровневой верификации изображений с вычислением Trust Score:
* **🟢 Trust Score >= 75% (Верифицировано):** Фотография подтверждена AI Vision как реальный снимок кампуса, получена из доверенных доменов (`.edu` Google Places, проверенные студенческие медиа).
* **🟡 Trust Score < 75% (Требует проверки / Honest Uncertainty):** Снимок из социальных сетей или форумов с потенциальным шумом или неполным контекстом.
* **🔴 Автоматический Drop (< 40%):** Изображение отбрасывается как рекламный рендер или сток.

### 🛡️ 2. Жесткая минус-фильтрация стоков и фейков
* Продвинутые поисковые директивы с минус-словами: `-stock -vector -freepik -shutterstock -alamy -depositphotos -clipart -render`.
* Черный список стоковых и агрегаторных CDN с валидацией метаданных и происхождения ссылки.

### 💬 3. Сбор живых отзывов (Reddit)
* Автономный сбор мнений студентов с помощью **Playwright**  и APIFY.
### ⚡ 4. Динамический JSON-пайплайн (Zero-Hardcode)
* Полное отсутствие захардкоженных списков ВУЗов.
* Любой введенный запрос нормализуется, после чего AI в Structured JSON Mode генерирует:
  * Год основания, типы степеней, топ-факультеты;
  * Реальную среднюю стоимость обучения и аренды жилья;

### 🌃 5. Campus Vibe Check, Night Safety Mode & Student Survival Tips
* **Campus Vibe Check:** Индекс студенческой жизни, исследовательский потенциал, загруженность кампуса и интернациональность.
* **Night Safety Mode:** Оценка ночной освещенности, круглосуточного транспорта, наличия кампусной охраны и безопасных зон.
* **Student Survival Tips:** Сгенерированные AI практические советы: где дешевле обедать, какие библиотеки работают 24/7 и как сэкономить на проездном.

### 🤖 6. AI Guardrails Assistant
* Встроенный AI-консультант.

## 6. 🛡️ Готовые компоненты, Данные и Ограничения (Components & Constraints)

* **UI & Дизайн-система:**
  * Кастомные компоненты на базе **Tailwind CSS** и **Lucide Icons** с поддержкой адаптивного темного интерфейса (Dark Glassmorphism).
  * Интерактивные модальные окна сравнения (Side-by-Side University Compare), полноэкранный Lightbox для фото и выдвижная панель AI-ассистента.
* **Источники исходных данных:**
  * Прямые сабреддиты студентов (Reddit)
  официальные академические порталы (`.edu`).
* **Ключевые системные ограничения (Constraints):**
  * ⏱️ **Время отклика системы:** Строго **<= 30 секунд** на полный цикл (парсинг + AI-верификация + сборка JSON + рендеринг).
  * 🚫 **Фильтрация стоков:** 100% блокировка доменов `shutterstock.com`, `freepik.com`, `istockphoto.com`, `stock.adobe.com` и изображений с признаками водяных знаков.
  * 🔐 **Безопасность:** Все API-ключи хранятся в защищенных серверных переменных окружения (`.env`) и никогда не утекают на клиент.

## 7. 🚀 Инструкция по запуску (Setup Guide)

### Предварительные требования:
* **Node.js**: версии `v18.17.0` или выше (рекомендуется LTS `v20.x`).
* **npm** или **pnpm** / **yarn**.

### Пошаговая установка:

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-org/locus-2026.git
cd locus

# 2. Установка зависимостей проекта
npm install

# 3. Установка браузерных бинарников Playwright для скрапинга Reddit
npx playwright install chromium

# 4. Настройка переменных окружения
cp .env.example .env
```

### Конфигурация `.env`:
Откройте созданный файл `.env` и укажите рабочие ключи:
```env
# Google Gemini API (Vision-верификация и генерация профиля)
GEMINI_API_KEY="AIzaSy..."

# Serper.dev API (Живой поиск изображений в Google)
SERPER_API_KEY="your_serper_key"

# Groq API (Опционально: ультрабыстрый суммаризатор)
GROQ_API_KEY="gsk_..."


### Запуск в режиме разработки:
```bash
npm run dev
```
Откройте в браузере: **`http://localhost:3000`**

## 8. 🧪 Тестовый сценарий для жюри (Verification Walkthrough)

Следуйте данному сценарию для полной оценки функционала LOCUS 2026:

1. **Ввод университета:** В поисковой строке на главной странице введите название любого университета
2. **Проверка SLA <= 30 секунд:** Обратите внимание на статус-трекер пайплайна (`PipelineTracker`) и шиммер-скелетоны. Полная обработка завершится быстрее 15-25 секунд.
3. **Проверка Trust Score:**
   * Убедитесь, что фотографии разделены на категории: 🟢 **>= 75%** (Верифицированные фото кампуса) и 🟡 **< 75%** (Требующие внимания).
   * Откройте фото в Lightbox — изучите бейджи источника и AI-заключение о достоверности.
4. **Проверка динамических данных (Zero-Hardcode):**
   * Ознакомьтесь с блоком **Overview Summary**: проверьте год основания, климатический блок, разбивку стоимости жизни и топ-факультеты.
5. **Проверка студенческих инсайтов (Reddit & Google):**
   * Перейдите к разделу **Student Voice (Reddit Reviews)**: просмотрите реальные треды и цитаты учащихся.
6. **Тестирование Guardrails AI-ассистента:**
   * Откройте чат-панель справа внизу.
   * Задайте вопрос по кампусу: *"Какая стоимость проживания в общежитии?"* -> Получите точный ответ.
